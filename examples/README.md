# Demo floor plan

`demo-floor-plan.png` is a fictional eight-room facility for upload demonstrations. It contains no real school or organization data. Generated with the built-in image generation tool for MapProj.

Prompt: Create a clean landscape architectural floor plan on white, with four rectangular rooms above and four below a central corridor, numbered 101 through 108, door openings, no furniture, no colors, and a fictional demo-center title. Use crisp walls and generous empty room interiors for manual polygon tracing.

Upload the PNG through the administrator building upload form. Room boundaries are deliberately not embedded: trace them using the calibration tool.
